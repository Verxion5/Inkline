## Base44 Dev Environment

TanStack Start (SSR) app using Vite 8 + Bun. Run with:

```
docker compose -f docker-compose.base44.yml up -d
```

- **Port**: 3000 (Vite dev server, `--host 0.0.0.0 --port 3000`)
- **Package manager**: Bun (`bun install --frozen-lockfile` at startup)
- **Base image**: `oven/bun:1` with source bind-mounted at `/app`
- **Env**: `.env` has Supabase keys; `/run/base44/app.env` holds platform secrets (e.g. `SUPABASE_SERVICE_ROLE_KEY`)
- **SSR**: TanStack Start via Nitro. `src/start.ts` is the start config; `src/server.ts` is the SSR entry
- **Auth**: Supabase client-side auth. `_app` route has `ssr: false` + `beforeLoad` redirect to `/auth` when unauthenticated. Anonymous visitors see the login page — this is expected behavior, not a bug
- **Routing**: `src/routeTree.gen.ts` is auto-generated by TanStack Router plugin — don't edit manually
