# Inkline engineering notes

TanStack Start (SSR) app. Read `README.md` for stack and environment variables.

## Layout

- `src/routes/` — file routes; `_app/` holds the signed-in studio screens.
  `routeTree.gen.ts` is generated by the TanStack Start Vite plugin — never edit it.
- `src/server.ts` — SSR entry wrapper that turns h3-swallowed 500s into a readable
  error page. `vite.config.ts` points `tanstackStart.server.entry` at it.
- `src/lib/*.server.ts` — server-only modules (AI provider, image provider).
  Route files and `*.functions.ts` ship to the client bundle, so import these
  dynamically or only from other `.server.ts` modules.
- `src/integrations/supabase/` — Supabase clients, auth middleware and cron auth.
  Client sessions live in `localStorage`.

## Conventions

- AI text/vision goes through `chatJSON()` in `src/lib/ai.server.ts`; image
  requests through `src/lib/imageProvider.server.ts`. Both take configuration from
  the server environment, never from the client.
- Panel artwork is drawn by `/api/generate-image` and streamed back as image
  frames; `src/lib/streamImage.ts` also accepts a single JSON response from
  providers that do not stream.
- Cron-protected routes call `authenticateCronRequest()` for constant-time bearer
  checks against `CRON_SECRET`.
